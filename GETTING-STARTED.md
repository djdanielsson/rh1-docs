## 💡 Key Concepts

### Application-of-Applications Pattern

```
root-app.yaml (you apply this once)
    ↓
Creates 7 child Applications
    ↓
Each child manages a directory of resources
    ↓
All resources deployed automatically with proper ordering
```

### Sync Waves

Resources deploy in order based on annotations:
- Wave -3: Namespaces (must exist first)
- Wave -2: Operators (must install before CRs)
- Wave -1: RBAC (must exist before pipelines run)
- Wave 0+: Application resources

### Auto-Sync and Self-Heal

- **Auto-Sync**: ArgoCD pulls from Git every 3 minutes
- **Self-Heal**: Manual changes in cluster are reverted to match Git
- **Prune**: Resources deleted from Git are removed from cluster
